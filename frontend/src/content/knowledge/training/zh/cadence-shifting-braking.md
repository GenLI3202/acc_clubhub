如果只能给新手三个技术建议，就是这三项：**用合理的踏频**、**在正确的时机换挡**、**在正确的位置刹车**。

## 一、踏频（Cadence）

### 为什么踏频重要

同样的功率输出，可以用「大齿比 + 低踏频」或「小齿比 + 高踏频」两种方式达成：

- **低踏频、大力量** → 肌肉负荷高，肌纤维疲劳快，膝关节压力大
- **高踏频、小力量** → 心肺负荷高，但肌肉与关节压力小

耐力骑行中，**肌肉疲劳通常比心肺更早成为限制因素**。所以在长距离骑行中提高踏频、降低单次踩踏力量，能显著延长你的续航。这也是为什么职业车手普遍维持较高踏频。

### 参考范围

| 场景 | 踏频范围 |
| --- | --- |
| 平路巡航 / 强度训练 | **85–100 rpm** |
| 爬坡 | **70–85 rpm** |
| 恢复骑 | 80–95 rpm（轻齿比） |

爬坡时受限于坡度和齿比，通常达不到平路的踏频，**能维持 70–80 已经不错**。

需要说明的是，「最佳踏频」存在明显的个体差异。训练有素的骑行者自选踏频通常落在 85–95 之间，但这是个范围而不是一个必须达到的数字。**不要为了追求某个数字而牺牲平稳性。**

### 没有码表怎么判断

看**身体的稳定性**：

- 踩踏平滑、高速，没有「踩空」或「被弹起来」的感觉 → 踏频合理
- 上半身随踩踏左右摇摆、屁股在坐垫上跳动 → **踏频过高**，超出了你目前的神经肌肉控制能力
- 每一下都需要明显发力、速度一顿一顿 → **踏频过低**，该换轻齿比了

踏频训练是一个**长期的有意识训练过程**，重点是在高踏频下仍然保持身体平稳，做到人车合一。说起来容易做起来难——这需要持续的刻意练习。

### 自测：找到你的经济踏频

一个可以自己完成的对照测试：

1. 找一段**能连续骑 10 分钟不被打断**的道路，每次测试都用这条
2. **第一次**：以 80 rpm 骑完，记录用时和自我疲劳感等级（1–10）
3. 放松骑 15–20 分钟
4. **第二次**：以 95–100 rpm 骑完，同样记录用时和疲劳感
5. **几天后重复**，但这次把顺序颠倒（先高踏频、后低踏频），以抵消先后顺序带来的偏差
6. 对比数据：**哪个踏频让你骑得更快、且疲劳感更低，那就是你的经济踏频**

想要更精细的结果，可以细化测试踏频：80 / 85 / 90 / 95 / 100 / 110 rpm。如果你最终落在 85–110 rpm 区间感觉最舒适，那是个好消息——说明你的踏频习惯已经在高效区间内。

> 单次实验的样本量很小，结论仅供参考。重点是观察**趋势**，不是追求精确数值。

## 二、换挡

### 第一原则：保持踩踏

**变速时切记保持踩踏。**

原理：变速器只是把链条**拨到**新的位置，真正让链条爬上新齿盘的，是踩踏产生的链条张力与传动。停止踩踏时变速，链条不会换位；重新发力的瞬间会「哐」一声强行挂上，对链条、飞轮、牙盘都是伤害。

但也**不要在踩踏力量最大时变速**（比如爬坡站立摇车的瞬间）。理想状态是：**保持转动，但短暂减轻踩踏力量**。

### 第二原则：提前预判

**变速要预判，变速要提前。**

尤其是爬坡。如果用较大的齿比入坡，踩两三下就蹬不动了，此时链条张力非常大，再想换到小齿比往往会听见一声巨响。偶尔一两次无伤大雅，长此以往会对链条、变速器、飞轮、牙盘造成不可逆的损伤。

**正确做法：在坡度上升之前就换好档。** 上坡前前牙盘一般提前换到小盘。

### 换挡时机的判断

随着坡度增加，维持原有踏频会越来越困难。判断时机的方法是：**在感觉到车速即将下降、踏频开始难以维持的那一刻换挡**，而不是等到已经蹬不动了。

- **换挡太早** → 突然失去阻力，脚下踩空，速度骤减；膝关节承托力被突然卸去，同样有受伤风险
- **换挡太晚** → 阻力不断增加，踏频完全无法保持，需要身体晃动或用更大力量勉强支撑，**膝关节承受过大压力而受伤**

两者都不可取。过早和过晚的换挡都会引起关节损伤。

### 前后拨的配合

- **路况变化小**（缓坡、起伏）→ 只用后拨微调即可
- **路况变化大**（大上坡、大下坡）→ 先调整前拨，再用后拨微调

### 避免交叉链（Cross-chaining）

**大盘 + 最大飞轮** 或 **小盘 + 最小飞轮** 会让链条严重斜拉，造成异响、加速磨损、传动效率下降，极端情况下会掉链。

需要这两个组合的齿比时，说明你该换前盘了。

> 长距离骑行路况千变万化，万金油的齿比并不存在。**要经常变速、及时变速。**

## 三、刹车

### 前刹还是后刹？

刹车时重心前移，**前轮的抓地力增加、后轮减少**。因此：

- **前刹**提供主要制动力（约 70%），但重心过于靠前时容易造成后轮腾空
- **后刹**制动力较弱，适合微调速度；但力道过猛会造成后轮抱死、横向偏移，导致重心不稳

**通常不建议单独使用任何一个。** 正确做法是**前后同时按压**，先以持续点刹的方式动作；如果需要进一步降低速度，改为持续轻压来调整；还是过快时慢慢增加压力。

**千万不可瞬间全力按压刹车。**

需要大力制动时，**身体重心主动向后移**（屁股稍微离开坐垫向后），这样能用上更多的前刹制动力而不至于翻车。

### 弯道：入弯前减速完毕

这是最重要的一条：**入弯之前就要先减速到过弯速度，而不是边过弯边刹车。**

原理：轮胎的抓地力是有限的，且需要同时承担**转向**和**制动**两种需求。弯道中前轮的抓地情况变化非常复杂，前轮或后轮意外锁死都会导致立即摔车。

所以：

- **入弯前完成减速**
- 弯中如必须刹车，力度前后平均、极其轻柔
- **避免弯道中的大力刹车**
- 走**外—内—外**路线，弯心贴近内侧，可以用更大的转弯半径通过
- 弯道内侧的踏板**保持在上方**，避免刮地

### 不同场景

**雨天**：

- 圈刹的轮圈刹车面会形成一层水膜，刹车皮无法即时产生摩擦力。**行进中可以先轻按刹车**，让刹车皮轻触刹车面排除水膜，制动性能会明显恢复
- 碟刹受雨天影响小得多，但仍会有短暂的初始衰减
- 整体上**制动距离按干燥路面的两倍预留**

**颠簸路面**：

- 建议握**下把位**，手指采用环扣式握住把手，不容易因路面跳动而脱手
- 臀部稍微离开坐垫，四肢呈微弯状态，用身体做减震，减少震动冲击

**急弯陡坡**：

- 握**下把位**，身体重心往后移
- 留意转弯侧的踏板不要碰到地面

**长下坡**：

- **间歇制动**，不要长时间持续按住刹车
- 圈刹：刹车皮与铝圈或碳圈长时间摩擦会过热，可能导致内胎爆胎或碳圈损伤。找机会停下充分散热
- 碟刹：同样会过热导致制动力衰减（fading），等碟片冷却后再继续

### 出发前的准备

如果确定行程中包含长距离下坡，**出发前就应该检查刹车线组是否完好无损**，并先到附近的上下坡测试刹车系统，确认轮组的刹车面有无异样、污渍或刮痕。
